# 🎮 محورِ انسانی — human-number-line

وب‌اپ تعاملی فارسی/RTL برای روش آموزشی **«محور اعداد انسانی + کارت نقش‌ها»** در درس اعداد صحیح.

## وضعیت فعلی

هر شش قسمت کامل شده است. نسخهٔ نهایی شامل متریال Liquid Glass مات/منشوری و **رفتارهای لیکوئید Glisse** (فشار ژله‌ای، لنز تب‌بار با نگه‌داشتن/کشیدن، سوییچ و اسلایدر فنری) است و برای لانچ در GitHub Pages آماده است.

- فایل اجرایی فعلی: `index.html` در ریشهٔ پروژه.
- نسخهٔ فعلی آفلاین است و از B Nazanin و KaTeX خودمیزبان در `assets/` استفاده می‌کند.
- قسمت ۱ کامل شده است: فونت B Nazanin، KaTeX خودمیزبان، مسیرهای نسبی، `.nojekyll`، گراف کد، خط پایه و تست‌های مرورگر.
- قسمت ۲ کامل شده است: `PRODUCT.md`/`DESIGN.md`، توکن‌ها، هدر/تب‌ها و ستون کنترل بازطراحی شدند؛ منطق ریاضی و متن آموزشی حفظ شد.
- قسمت ۳ کامل شده است: صحنه/بازخورد، محور، حرکت قابل‌توقف و رگرسیون.
- قسمت ۴ کامل شده است: راهنما با GSAP/ScrollTrigger، نوار پیشرفت، کارت‌ها/پیش‌نمایش چاپ، کاهش حرکت و پولیش. متن آموزشی و منطق ریاضی حفظ شد.
- قسمت ۵ کامل شده است: متریال Liquid Glass مات/منشوری با Glisse 0.5.0 خودمیزبان (بدون React)، رفع flip در WebKit، fallbackهای دسترس‌پذیری و تست سه‌موتوره.
- قسمت ۶ کامل شده است: پورت رفتارهای لیکوئید Glisse (فنر/press/لنز تب/سوییچ/اسلایدر)، حذف متن Cloudflare از فوتر، تست نهایی سه‌موتوره + لمس واقعی، چاپ/آفلاین/subpath، و آماده‌سازی لانچ.
- پوشهٔ ورودی قبلی حذف شده است؛ فایل‌های پروژه اکنون در ریشه قرار دارند.

## اجرای محلی

فایل `index.html` را در مرورگر باز کنید. برای نسخهٔ فعلی به اینترنت، نصب، Node.js یا بیلد نیاز نیست.

## لانچ در GitHub Pages

۱. یک ریپو به نام `human-number-line` بسازید.
۲. فقط این فایل‌ها را در ریشهٔ ریپو بگذارید: `index.html`، پوشهٔ `assets/`، و `.nojekyll` (فایل‌های توسعه مثل `docs/`، `tests/`، `tools/`، `.opencode/` لازم نیستند).
۳. در Settings → Pages، منبع را شاخهٔ `main` و پوشهٔ `/ (root)` انتخاب کنید.
۴. آدرس نهایی: `https://<نام‌کاربری‌تان>.github.io/human-number-line/`.

همهٔ مسیرها نسبی‌اند؛ زیرمسیر `/human-number-line/` locally تست شده و بدون 404 است. حجم بستهٔ انتشار حدود 1.9 MB (زیر بودجهٔ 5 MiB).

## هدف انتشار

هدف نهایی طبق SRS، انتشار روی **GitHub Pages** از ریپوی `human-number-line` است:

```text
https://<نام‌کاربری‌تان>.github.io/human-number-line/
```

زیرساخت انتشار تست شده است (شبیه‌سازی محلی زیرمسیر)؛ انتشار واقعی فقط با دستور کاربر و نام کاربری گیت‌هاب انجام می‌شود. فایل‌های توسعه مانند `.opencode/`، `.specify/` و آرشیوها نباید وارد bundle اجرایی بازی شوند.
